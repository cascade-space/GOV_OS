## 🆘 Troubleshooting

### Can't Connect?
Make sure the server is running:
```bash
npm run dev:officer
```

### Port Already in Use?
Kill the process:
```bash
npx kill-port 3001
```

### Page Not Loading?
1. Check if server is running
2. Clear browser cache
3. Try hard refresh (Ctrl + Shift + R)
